# 构建、发布与设备验收

当前版本 2.0.0 / 2000000。build.ps1 已准备，当前输出 debug unsigned HAP，不含签名证书。正式地址、应用 bundleName/vendor 和华为平台配置仍待填写；系统推送尚未接入。

## 运行自动检查

```powershell
Set-Location .\server
npm ci
npm test
npm run sync:policy
Set-Location ..
```

后端测试使用临时数据库；不复制真实用户聊天做测试。政策修改时同步生成客户端离线 Policy.ets。

## 生成安装包

```powershell
.\build.ps1 -Mode debug -DevEcoHome '实际DevEco Studio安装目录'
```

HAP 及 .hap.json 清单位于 artifacts；清单含版本、模式、签名标记、大小、构建时间和 SHA-256。未配置签名时输出 human-ai-2.0.0-debug-unsigned.hap，不能直接作为真机安装包分发。

在 DevEco Studio 的 Signing Configs 配置自己的应用和设备签名后重新构建。通过 IDE Run 安装到实际设备；也可对已签名 HAP 使用 hdc -t 实际设备 install -r 实际签名HAP路径。不要把证书、密码、设备标识或私钥提交到仓库。

正式构建先实际部署 HTTPS，再配置正确的 bundleName、vendor 和签名：

```powershell
.\build.ps1 -Mode release -DevEcoHome '实际DevEco Studio安装目录' -ServiceUrl https://实际域名
```

脚本拒绝空地址、HTTP、回环地址和示例域名；临时注入地址后恢复源码。正式版隐藏地址设置，开发版允许保存地址。发布前在华为平台关联对应应用，版本升级保持 bundleName 与签名一致，不把开发证书用于正式分发。

## 两台设备核心验收

每项记录设备型号、系统版本、应用版本、操作和结果。以下尚未在真实鸿蒙设备完成。

| 场景 | 操作 | 必须满足 |
| --- | --- | --- |
| 初次使用 | A 注册用户，B 注册并开放 AI 接聊，创建对话 | 字段错误逐项显示，真实身份说明清楚 |
| 重启登录 | 强制结束/重启 A、B 应用 | 自动恢复同一账号与上次身份；历史仍在 |
| 离线退出 | 断网后退出 A，再切换其他账号 | 本机退出立即完成；不显示 A 的草稿、消息或队列 |
| 快速连发 | 同一会话连续发 10 条带序号文字 | 顺序一致，每条只出现一次，确认后仍持久保存 |
| 超时重试 | 模拟请求已保存但响应丢失；原条重试 | 原 clientMessageId，只有一条服务器记录，失败文字仍可见 |
| 重启待发 | 发失败消息后结束并重启应用 | 未确认原条可重试，后续消息不越过它 |
| 断线补齐 | A 断网，B 连续发消息，再恢复 A | 断线消息全部补齐，不重复，未读与摘要正确 |
| 实时失败 | 仅阻断 /realtime，保留 HTTP | 显示回退状态，轮询仍收消息，恢复后自动重连 |
| 历史分页 | 至少 235 条历史，打开后向上阅读 | 首屏最近消息，前插不跳走，有新消息按钮 |
| 会话分页 | 至少 145 个会话/AI，搜索、分页、置顶 | 可看到末页；刷新保留加载窗口，排序和隐藏一致 |
| 可见已读 | A 停在旧历史，B 发新消息，再滑到新消息 | 未显示时不标已读；实际显示后 B 看见已读 |
| 多设备 | 同账号第三台设备修改资料、接聊与免打扰 | 更新同步，正在编辑的设置不被覆盖 |
| 改密/设备退出 | 改密码、退出其他设备，旧设备请求 | 旧登录撤销，给出原因，不能继续接收实时消息 |
| 拉黑/举报 | 双方尝试发送、解除、分类举报并处理 | 拉黑关闭发送，重复举报不新增，结果可查看 |
| 管理处罚 | 网页警告、临封、永久封禁、解封 | 有原因/时间/日志，立即断连；解封需重新登录 |
| 注销 | 注销 A，B 仍在线；另有 B 断线后重连 | A 资料与本人正文移除，必要证据按政策保留 |
| 服务重启 | 发确认消息后重启后端 | 账号、会话、消息编号与设置仍在 |
| 备份恢复 | 停服，恢复已验证备份，重启登录 | 完整性通过，旧凭据失效，后续注销不复活 |

邮件配置后另测真实收件、过期/错误次数、一次性消费、邮箱更换/解绑、找回密码及旧凭据撤销。不要使用真实用户数据进行断网/恢复演练。

## 鸿蒙布局与资源

检查小屏、横竖屏、刘海/底部安全区、深色与浅色、多行输入、键盘展开、系统返回键、页面来回切换、系统大字体和读屏。长昵称、超长文字、空列表、断网/错误/加载状态都要测试。

记录长会话内存、30 分钟前台/后台电量、WebSocket 心跳和请求数量。后台应停止实时/轮询，前台立即补齐；当前不保证后台收到消息提醒。GET_NETWORK_INFO API 编译警告虽然已有权限声明，仍需在目标 SDK / 真机检查网络状态行为。
